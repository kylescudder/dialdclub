# Diald Club Marketing Site

Astro marketing and compliance site for Diald Club.

## Commands

```sh
bun install
bun run dev
bun run build
bun run preview
```

The development server runs on port `4175`.

From the repository root, run the same site commands through the root scripts:

```sh
bun run dev
bun run build
bun run preview
```

Netlify builds from the repository root with `cd Site && bun run build` and publishes `Site/dist`.
